# Frontend Folder

This folder is for everything the user sees in the browser.

## What goes here

- HTML files
- CSS styles
- JavaScript code
- images and icons
- user interface components

## Simple Folder Idea

```text
frontend/
├── README.md
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── assets/
    ├── images/
    └── icons/
```

## Easy Guide for Members

- If you are making pages or design, work here.
- If you are styling buttons, text, or layouts, work here.
- If you are adding browser interaction, work here.
- Do not put server code here.

## Beginner Note

If you are new, think of frontend as the part the user sees and clicks.
It is the visible side of the project.
