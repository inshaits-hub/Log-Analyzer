# Backend Folder

This folder is for the server side of the project.

## What goes here

- API code
- database code
- server logic
- validation and business rules
- scripts for data handling

## Simple Folder Idea

```text
backend/
├── README.md
├── src/
│   ├── app.py
│   ├── routes/
│   ├── controllers/
│   ├── models/
│   └── utils/
├── tests/
└── .env
```

## Easy Guide for Members

- If you are building an API, work here.
- If you are connecting to a database, work here.
- If you are writing server logic, work here.
- Do not put frontend design files here.

## Beginner Note

If you are new, think of backend as the part that works behind the scenes.
It stores data, checks data, and sends data to the frontend.
